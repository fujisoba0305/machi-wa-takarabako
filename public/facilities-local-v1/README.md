Source extract: https://download.geofabrik.de/asia/japan/kanto.html
The JSON files in this directory are the downloadable adapted database; conditions and integrity manifest are in src/data.
56,701 OSM records using the existing application tag conditions. This is not a guarantee of current opening hours, access or exact entrances.
Coordinates may be retained representative points. Actual destination photographs are separate from this OSM dataset.
Asset names contain SHA-256 prefixes. Never change bytes under an existing filename; publish a new name and matching manifest/cache-header rules.
